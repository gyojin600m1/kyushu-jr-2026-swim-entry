九州の小学生・中学生の大会。同じ会場で同時に行われる日本選手権(25m)は[別のアプリ](https://gyojin600m1.github.io/japan-champs-25m-2026-swim-entry/)。

## できること

- **選手** … 名前・チーム名で検索。鹿児島は先頭に⭐チップ（日付ボタンでその日に泳ぐ人だけ）。種目の行にはタイムの上に実施日を小さく表示。
- **種目** … 種目ごとの出場者をエントリータイム順に。◀ ▶ で前後の種目へ。
- **日程** … 種目一覧。日付で絞り込める。

各種目の実施日は日本水泳連盟「2026年度 日本選手権(25ｍ) 競技日程」（10/1現在）による。

| 日 | 九州ジュニアの種目（男女とも） |
|---|---|
| 10/10(土) | 100m背泳ぎ(中)・100m平泳ぎ(中)・100m個人メドレー(小・中) |
| 10/11(日) | 50mバタフライ(小・中)・50m平泳ぎ(小・中)・100m自由形(中) |
| 10/12(月・祝) | 50m自由形(小・中)・50m背泳ぎ(小・中)・200m個人メドレー(小・中)・100mバタフライ(中) |

画面の No. はこのアプリでの通し番号（公式の競技No.とは違う）。組・レーンは大会側の発表待ち。

## 速報（結果）

[公式SEIKO速報](https://swim.seiko.co.jp/2026/S70702/index.htm)の種目別結果PDFを読み取り、氏名・所属・種目を既存エントリーと全件照合して取り込む。

- **鹿児島結果タブ**で鹿児島の選手だけの予選・決勝をまとめて表示。「結果あり」と「全員・速報待ち」、男女・日程で絞り込める。既存の鹿児島所属チーム設定を使用。
- **速報タブ**が初期画面。予選・決勝を切り替え、選手名・順位・タイムをアプリ内に直接表示。選手名・チーム・種目を検索し、日程・男女で絞り込める。先頭ボタンもアプリ内の結果表示を開く。
- **種目画面**で予選・決勝を切り替える。決勝は同じ種目内に収録し、メダルは決勝のみ。公式PDFへ直接移動できる。
- **選手画面**を開くと予選・決勝の記録と順位が見える。未開催は速報待ち。
- 10/10確認：8種目、予選210件・決勝64件。公式PDFの全274行と一致。
- 大会中は既存のGitHub Actionsが自動更新する。アプリの確認時刻を表示し、最新は公式速報で確認する。
- 手動更新：`python3 -m pip install pdfplumber`、`python3 tools/live_results.py`（当日だけなら `--today`）。照合に失敗した場合は書き込まず、変更なしは終了コード3。
